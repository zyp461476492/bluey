## 2. 功能需求

### F1 猜词主循环

**用户故事**
> 作为孩子，我打开应用就看到一张图，我猜它是什么，几秒后答案自己出来了，
> 我想继续就点"下一题"。

**流程**（状态机状态名与 `05-architecture.md` 保持一致）
```
IDLE → REVEALING_MEDIA → COUNTDOWN(5s) → ANSWER_SHOWN → (next) → REVEALING_MEDIA
```

**验收标准**

| 编号 | 标准 |
| --- | --- |
| F1-1 | 进入应用后自动展示第一题的图片，无需任何点击 |
| F1-2 | 图片加载完成后开始 5 秒倒计时（可配置，见 F5-3） |
| F1-3 | 倒计时期间答案文本**不可见**（DOM 中可存在，但视觉不可见、不可被屏幕阅读器读成答案） |
| F1-4 | 倒计时结束自动揭晓答案，揭晓有明确的视觉变化（不是仅仅文字出现） |
| F1-5 | 揭晓后可点"下一题"进入下一题；也可点"重看"回到本题的倒计时前状态 |
| F1-6 | 任何一步都不需要键盘输入文字 |
| F1-7 | 图片加载失败时展示 `fallbackEmoji` + 词条提示，流程不中断 |
| F1-8 | 揭晓动效：图片轻微放大 + 答案区淡入上移，总时长 300ms（见 `03-ux-devices.md` §2.1）；`prefers-reduced-motion` 时降级为纯淡入（无位移、无缩放） |

### F2 题目模式

**模式 A · 闪卡模式（`flashcard`）** — 默认给 2–3 岁（toddler）
- 图 + 中英文 + 发音**同时**出现，没有倒计时、没有悬念、没有选择题。
- 3.5 秒后自动翻下一张；点一下暂停/继续。
- 理由：2 岁还不会"猜"（需要"我知道答案你不知道"的心理理论），
  他们玩的是命名游戏。详见 `11-curriculum-design.md` §1。

**模式 B · 揭示模式（`reveal`）** — 默认给 4–5 岁（preschool）
- 只出图，孩子口头猜，3 秒后揭晓。无选择题、无对错。

**模式 C · 选择模式（`quiz`）** — 默认给 6–8 岁（school）
- 出图 + 4 个选项（1 正确 + 3 干扰项）。
- 孩子点选后**立即**判定；5 秒内未选则直接揭晓正确答案。
- 选错不显示"错误"，而是把正确选项高亮 + 揭晓，附一句中性提示。

**验收标准**

| 编号 | 标准 |
| --- | --- |
| F2-1 | 模式由年龄档决定（见 F6），也可在设置中单独覆盖 |
| F2-2 | 选择模式的 4 个选项位置每题随机，正确答案不固定在某一位置 |
| F2-3 | 选项文本长度溢出时不得撑破卡片（截断或缩小字号） |
| F2-4 | 选择模式的选项可通过遥控器方向键移动焦点、确认键选择 |
| F2-5 | flashcard 模式不出现倒计时进度环、不出现选项、不出现"揭晓"动作 |
| F2-6 | flashcard 模式自动翻页可被任意点击暂停，暂停状态可见 |

### F3 题库与分类

**验收标准**

| 编号 | 标准 |
| --- | --- |
| F3-1 | 题库格式遵循 `04-data-model.md`，一个分类一个 JSON 文件 |
| F3-2 | 支持按分类筛选出题；「全部」为默认 |
| F3-3 | 同一轮内不重复出题，题库耗尽后提示"本组完成"并可重开 |
| F3-4 | 题库 JSON 结构错误时，界面给出可见错误提示而不是白屏 |
| F3-5 | 新增一个分类 = 新增一个 JSON + 在 `data/questions/index.json` 注册，无需改 JS |

### F4 发音与中英切换

| 编号 | 标准 |
| --- | --- |
| F4-1 | 揭晓时自动朗读答案（浏览器 `speechSynthesis`），默认开启 |
| F4-2 | 朗读顺序：先英文（`en-GB`）再中文（`zh-CN`）；语言设为单语时只读那一种 |
| F4-3 | 提供「再听一次」按钮，随时重播（**电视上常见"接口存在但无声"，必须能手动重试**） |
| F4-4 | 不支持 `speechSynthesis` 时按钮置灰并给出提示，**流程完全不受影响** |
| F4-5 | 任何语音报错、超时、无语音包都静默降级；**不得用音频是否成功决定状态机走向** |
| F4-6 | 切题时立即停止上一题的朗读，避免声音叠加 |
| F4-7 | 语言切换（中/英/双语）只影响答案展示与朗读，不影响题库 |
| F4-8 | 设备缺英文语音时，给家长一次性提示（轻提示条），不打断孩子流程 |

> 实现注意：部分浏览器要求先有用户手势才允许发声，所以首次点击/按键时会
> 用一个静音空串"解锁"。内部有看门狗（按字数估算时长），
> 防止某些 TV 浏览器 `onend` 永不触发导致朗读链卡死。
>
> **两个已踩过的 Chrome 坑**（见 `MEMORY.md`）：
> `cancel()` 后立刻 `speak()` 会吞掉新句子；`voice.lang` 可能是 `en_US`
> 下划线格式，直接赋给 `u.lang` 会静默失败。

### F7 主题（深色 / 浅色）

| 编号 | 标准 |
| --- | --- |
| F7-1 | 提供深色与浅色两套配色，顶栏一键切换 |
| F7-2 | 选择写入 `localStorage`，刷新后保持 |
| F7-3 | 从未选择过时跟随系统 `prefers-color-scheme` |
| F7-4 | 切换主题不重载页面、不丢失当前题目进度 |
| F7-5 | 两套主题下答案文本与背景的对比度均 ≥ 4.5:1 |

### F5 进度与设置

| 编号 | 标准 |
| --- | --- |
| F5-1 | 设置项写入 `localStorage`，刷新后保持 |
| F5-2 | 记录本轮已出题 ID，避免重复；可选记录"已掌握"词条 |
| F5-3 | 倒计时秒数可配置（默认由年龄档决定，见 F6）；设置面板提供 自动 / 3 秒 / 5 秒 / 8 秒 四档，「自动」跟年龄档默认值，其余为显式覆盖；flashcard 模式无倒计时，不显示该行 |
| F5-4 | 提供「重置进度」入口，二次确认后清空本地数据 |
| F5-5 | 发音语速可配置：设置面板提供 慢 / 正常 / 快 三档，分别为年龄档语速（`age-profiles.ttsRate`）的 ×0.8 / ×1.0 / ×1.25，结果限制在 0.5–1.5；默认「正常」（即年龄档默认语速）；修改后从下一次朗读生效 |
| F5-6 | 设置面板行顺序：语言 → 发音 → 语速 → 倒计时 → 主题外观 → 年龄段 → 主题；面板打开时焦点落在第一项（不是关闭按钮） |

### F6 年龄档（P0）

**用户故事**
> 作为家长，我第一次打开时被告知"选一个年龄段"，孩子 2 岁就点 2–3 岁，
> 进去直接是闪卡，不是我看不懂的选择题。

**验收标准**

| 编号 | 标准 |
| --- | --- |
| F6-1 | 首次启动显示三个年龄档大按钮（2–3 / 4–5 / 6–8），必须选一个才能进入 |
| F6-2 | 年龄档决定模式、倒计时、选项数、是否显示文字、TTS 语速（配置项见 `11` §3.2） |
| F6-3 | 只出 `minAge <= 当前档` 的词条 |
| F6-4 | 主题列表只显示"当前档下有词"的主题 |
| F6-5 | 设置里可切换年龄档，切换后立即生效（无需刷新） |
| F6-6 | 2–3 岁档下不出现任何选择题 |

## 3. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 首屏可交互 < 1.5s（本地）；切题无白屏，下一题预加载 |
| 兼容 | Chrome / Edge / Safari 近两年版本；Android TV 上的 Chromium 内核浏览器 |
| 离线 | 断网 100% 功能可用，无任何外部网络请求 |
| 可访问性 | 文本对比度 ≥ 4.5:1；关键操作可键盘完成；`prefers-reduced-motion` 生效 |
| 素材体积 | 单张图 ≤ 200KB（webp/jpg），全部素材合计目标 ≤ 30MB |
| 分辨率 | 图片长边 ≥ 800px 以适配 TV；不依赖固定像素布局 |

## 4. 待确认问题

以下问题在进入 M1 前需要拍板，拍板结果写进 `07-decisions.md`：

1. **动图范围**：GIF / APNG / 短视频（mp4）是否都要支持？→ 建议初版只支持静态图 + GIF，mp4 留到 M4。
2. **答案时机**：5 秒是硬性倒计时，还是"图片加载完成后 5 秒"？→ 建议后者，避免加载慢导致思考时间被吃掉。
3. **选择模式的干扰项**：从全题库随机抽，还是同分类内抽？→ 建议同分类（语义接近，才有难度）。
4. **是否需要"家长添加词条"的图形界面**？→ 初版纯 JSON 编辑，界面留到 M5。
5. **是否需要护眼提示（20 分钟休息）**？→ 初版不做，记入 backlog。
