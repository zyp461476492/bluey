为什么要装两次？
Windows 有两套语音：SAPI5（旧）和 OneCore（新，Edge 与新款 Chrome 用）。 只装语言、不装「语音」组件的话，两套都可能没有英文。
您这台机器：SAPI5 有 Zira (en-US)，但 OneCore 只有中文三个 （慧慧 / 康康 / 瑶瑶），所以 Chrome 里英文才不出声。

命令行方式（需要有管理员权限的 PowerShell）： 
Add-WindowsCapability -Online -Name "Language.Speech~~~en-US~0.0.1.0"
装完重启浏览器。
